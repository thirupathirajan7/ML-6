# ML-TASK-6

A machine learning project using Python, pandas, scikit-learn, and visualization libraries.

## Description

This repository contains a Jupyter notebook (`Untitled8 (1).ipynb`) for exploratory machine learning tasks. The notebook begins by importing essential data science and machine learning libraries.

## Libraries Used

- **pandas** – Data manipulation and analysis
- **numpy** – Numerical computing
- **matplotlib.pyplot** – Data visualization
- **seaborn** – Statistical data visualization
- **scikit-learn** – Machine learning (train_test_split, StandardScaler, OneHotEncoder, ColumnTransformer)
